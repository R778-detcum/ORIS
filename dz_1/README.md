## Как запустить

### 1. Запуск сервера

Открыть терминал в папке проекта и выполнить:

python server.py

В консоли появится строка:

[*] Сервер запущен на 127.0.0.1:5555



### 2. Запуск клиента

Открыть второй терминал в той же папке и выполнить:

python client.py

Можно открыть несколько таких терминалов каждый будет отдельным
клиентом. Все клиенты работают с одним и тем же списком задач на сервере.


## Команды клиента
 `/add <текст>`  
`/list`   
`/done <номер>`

`/quit` 

## Как реализована одновременная работа нескольких клиентов

В `server.py` сервер в бесконечном цикле принимает подключения.
На каждого нового клиента запускается отдельный поток:

    while True:
        client_sock, addr = server.accept()
        threading.Thread(
            target=handle_client,
            args=(client_sock, addr),
            daemon=True
        ).start()

Функция `handle_client` обслуживает одного клиента: принимает команды,
изменяет список задач и отправляет ответ. Так как на каждого клиента
создаётся свой поток, сервер может обслуживать несколько клиентов
одновременно, и они не мешают друг другу.

## Где и зачем используется синхронизация

Общий список задач хранится на сервере:

    tasks = []
    tasks_lock = threading.Lock()

Список изменяется из нескольких потоков (по одному на каждого клиента).
Если два клиента одновременно добавят или отметят задачу, без защиты
может возникнуть состояние гонки,например одна из задач потеряется
или номер задачи окажется неверным.

Чтобы этого не было, все операции с `tasks` выполняются внутри
блокировки:

    with tasks_lock:
        tasks.append({"text": text, "done": False})

так же защищены чтение списка (`/list`) и изменение задачи (`/done`).
С помощью `tasks_lock` в один момент времени список изменяет только
один поток, поэтому данные всегда остаются корректными.
