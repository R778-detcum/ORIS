## Какие изменения внесены
1. В класс `ReceiveThread` добавлен сигнал `disconnected` и блок `try/except` для перехвата сетевых ошибок.
2. В `MainWindow` реализован обработчик `on_disconnected`, который блокирует ввод и выводит системное сообщение об обрыве связи.
3. В класс `SendThread` добавлен метод `stop()`, который отправляет в очередь `None` для завершения потока.
4. В `MainWindow` переопределен метод `closeEvent`, который вызывает остановку потока отправки при закрытии окна.

## Как обрабатывается потеря соединения
Если сервер выключается, метод `recv()` возвращает `None` или выбрасывает исключение. В `ReceiveThread.run()` это ловится, генерируется сигнал `disconnected`, и цикл `while` прерывается. `MainWindow` получает сигнал и выводит в чат сообщение `[Система] Соединение с сервером потеряно.`, после чего поля ввода блокируются.

## Как организована остановка SendThread
При закрытии окна вызывается `closeEvent`. В нем вызывается метод `self.send_thread.stop()`, который кладет `None` в очередь `Queue`. Поток `SendThread` извлекает `None` из очереди и делает `break`, завершая свой цикл. После этого `MainWindow` дожидается завершения потоков с помощью `wait()`.

## Какие проверки выполнены
1. Запущен сервер и клиент.
2. Отправлены сообщения (проверена работа чата).
3. Сервер остановлен (Ctrl+C). Проверено, что клиент не зависает и выводит сообщение о потере связи, интерфейс блокируется.
4. Окно клиента закрыто. Проверено, что программа завершается без ошибок и зависаний в терминале.
