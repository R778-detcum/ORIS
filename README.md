## Формат сообщения
Каждое сообщение состоит из заголовка и тела: 4 байта длина команды, 4 байта длина данных, потом сама команда и данные (struct, порядок байт !II). Максимальный размер данных 10 МБ.

## Поддерживаемые команды
- JOIN <username> регистрация клиента под именем
- TEXT <message>  рассылка сообщения всем остальным
- LIST запрос списка подключённых пользователей
- QUIT корректное завершение соединения
- SYSTEM, ERROR  служебные ответы сервера

## Кто за что отвечает
- protocol.py упаковка и распаковка сообщений, чтение ровно N байт (recv_exact), проверка размера.
- server.py принимает клиентов в отдельных потоках, хранит их в словаре, рассылает сообщения, обрабатывает команды, переживает обрыв соединения.
- client.py подключается к серверу, отправляет JOIN, держит 2 потока: один читает ввод с клавиатуры, второй слушает входящие сообщения.

## Запуск
python3 server.py
python3 client.py <username>
