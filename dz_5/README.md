# Гостевая книга v3

Реализованы следующие функции:
1. **Лайки:** `POST /notes/<id>/like` увеличивает счетчик лайков. У новых заметок поле `likes` по умолчанию равно 0.
2. **Сортировка:** `GET /notes` принимает параметры `sort` (id, likes) и `order` (asc, desc). Сортировка применяется до пагинации.
3. **Статистика:** `GET /authors` возвращает список авторов с количеством их заметок и суммой лайков, отсортированный по имени.
4. **Массовое удаление:** `DELETE /notes?author=<имя>` удаляет все заметки автора и возвращает количество удаленных.
5. **Сохранение:** Все данные автоматически сохраняются в файл `notes.json` при любом изменении.
6. **Тесты:** В `client.py` добавлены проверки для всех новых эндпоинтов.
